Vaulted vs Vaultless Tokenization

Every platform in this list answers one question first: where does the original value go after it is tokenized? The PCI Security Standards Council’s Tokenization Product Security Guidelines (April 2015) name the two answers.

How Vaulted Tokenization Works

The original is encrypted and stored in a vault, and your systems get a random token back. The PCI SSC calls these reversible non-cryptographic tokens.

A stolen token reveals nothing. To get the original, a caller must ask the vault, so the vault’s access rules and logs decide who sees what.

How Vaultless Tokenization Works Without a Vault

Nothing is stored. A secret key, usually through format-preserving encryption, turns the value into a token and turns it back; the PCI SSC calls these reversible cryptographic tokens.
