The old site hand-maintained this JSON separately and it had already drifted: nopii/faqs listed 14 questions but only 12 in schema (and one schema entry matched no question on the page); vault/faqs had 10 visible, 9 in schema. Google requires schema to match visible content, so this reads the rendered content instead — one source, no drift possible. */ -}} {{- /* Opt-in: not every

.*?
` $block) -}} {{- $a = . | replaceRE `<[^>]*>` "" | htmlUnescape | strings.TrimSpace -}} {{- end -}} {{- if and $q $a -}} {{- $qa = $qa | append (dict "@type" "Question" "name" $q "acceptedAnswer" (dict "@type" "Answer" "text" $a)) -}} {{- end -}} {{- end -}} {{- with $qa -}} {{- end -}} {{- end -}}
